Welcome to the Kube-VIM documentation.

Kube-VIM is a Kubernetes-native, ETSI NFV-MANO compliant Virtual Infrastructure
Manager. These pages cover what it is, how it works, how to run it, and how it
conforms to the ETSI reference points.

New here? Start with the [Overview](/docs/overview/), then follow
[Getting Started](/docs/getting-started/).
